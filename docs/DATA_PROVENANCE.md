# Data Provenance

## v1 (original, preserved unchanged)

- `data/sample_documents_v1.jsonl` (10 documents), `data/evaluation_queries_v1.jsonl` (10 queries).
- Shipped with the repository as received (baseline commit `93ed1b8`). Preserved byte-for-byte under
  the `_v1` filename so the original README numbers remain independently reproducible against the
  exact data that produced them. Never modified, never deleted.

## v2 (expanded, now the active default at `data/sample_documents.jsonl` / `data/evaluation_queries.jsonl`)

- **150 documents / 150 queries**, generated by
  `scratchpad/generate_corpus.py` (a deterministic, non-random script — re-running it reproduces the
  exact same files byte-for-byte since every document and query text is a literal, hand-authored
  string, not sampled).
- **Domain:** identical to v1 — a synthetic technical-support knowledge base. Ten topic clusters
  (network, account, hardware, software, storage, collaboration, messaging, security, mobile,
  peripherals), 15 documents each, each covering a distinct, plausible support scenario within its
  cluster (no two documents in a cluster describe the same underlying problem).
- **Authorship and judgment process — disclosed explicitly:** every document and every query was
  written by the engineer/assistant performing this project, in the same spirit and style as the
  original 10-item v1 set. Relevance grades were assigned by the same author who wrote the documents,
  at authoring time. **This is a single-annotator, non-independent judgment process.** It is not an
  independently reviewed, human-labeled production dataset, and every results document in this
  repository (`BENCHMARK_REPORT.md`, `PROJECT_EVIDENCE.md`, etc.) must state this plainly rather than
  imply otherwise. This mirrors exactly how the original v1 set was produced — the expansion changes
  scale, not the nature of the evidence.
- **No behavioral data of any kind was fabricated.** There is no click data, popularity signal,
  session history, or personalization signal anywhere in v2 — only documents, queries, and graded
  topical-relevance judgments, matching the original repository's scope.
- **Relevance scale:** unchanged 0–3 grade (0 irrelevant/implicit, 1 marginally relevant, 2 relevant,
  3 highly relevant — matching the README's existing definition). Grade 3 is assigned to each query's
  intended primary target document; a subset of queries (16/150, ≈10.7%) also carry one grade-1
  secondary document, similar in spirit to the ~50% secondary-relevance rate in v1, chosen for
  documents in the same cluster that are plausibly, but not primarily, relevant to that query.
- **Query phrasing is intentionally not uniform.** Roughly half the queries reuse some vocabulary from
  their target document's title/body; the other half are deliberate paraphrases using different
  surface words for the same underlying problem (e.g., "connected to vpn but can't reach shared
  drives" for the document titled "VPN connects but internal file shares are unreachable"). This
  mixture exists so that a **lexical-gap slice can be discovered from measured text-overlap statistics
  later (Section 17 of the task), rather than assumed or hand-picked** — the author did not tag which
  queries are "the paraphrased ones"; that determination is made independently from token-overlap
  measurements in a later phase, exactly as the task requires.
- **New metadata fields added, used later as candidate ranking-feature material (Section 12):**
  `metadata.last_updated` (ISO date, plausible authoring/review date per document) and
  `metadata.source_authority` (`official` vs `community`, reflecting whether the KB article reads as
  an official support procedure vs. a community-sourced tip). Both are genuine authored attributes of
  each document, not derived from any real user behavior.
- **No duplicate or near-duplicate queries or documents.** Verified programmatically: 150/150 unique
  document ids, 150/150 unique query strings, every `relevance` document id resolves to a real document
  id in the corpus.

## What this expansion is NOT

- Not a different domain. Not a licensed or scraped external dataset. Not click-through, popularity,
  or personalization data. Not independently reviewed by a second annotator. Not intended to be
  presented as a production-scale, production-sourced benchmark — it remains a "reproducible,
  disclosed, synthetic benchmark," now at a scale that supports real splits, ablations, and a lexical-
  gap slice, rather than a corpus so small that those phases are statistically meaningless.
